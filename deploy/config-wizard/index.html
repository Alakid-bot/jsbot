JSBot Configuration Wizard

Discord Bot 配置向导

在浏览器中填写 Discord Token、服务器 ID、频道/角色 ID、FastGPT Key 等信息。Zeabur 在线模式可直接保存配置并重启 Bot。

本地处理 本页面可本地生成配置；部署到 Zeabur 后会通过密码保护并保存到服务器持久化目录。
1

基础信息

填写 Bot Token 和 Discord 服务器 ID。服务器 ID 需要在 Discord 开发者模式中复制。

2

角色与常用频道

每行一个 ID。暂时不用的频道可以留空，生成结果会写成 null。

3

Forum / Thread 自动化

用于分析或清理不活跃帖子；不需要时保持 disabled。

4

身份组申请

如果暂时不用身份组申请功能，全部留空即可。

5

FastGPT / AI 答疑

这个 Bot 当前配置 FastGPT Endpoint。OpenAI/DeepSeek 等模型 SK 通常放在 FastGPT 侧。

6

社区治理 / 投票系统

不使用法院/议会流程时保持关闭。

7

运行监控

用于展示 Bot 在线状态、Ping、角色人数等信息。

8

导入 / 重置

可以导入已有 config.json 继续编辑。

9

在线保存 / Bot 控制

在 Zeabur 域名访问时，配置会保存到服务器的持久化 data/config.json。
