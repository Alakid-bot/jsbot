JSBot Configuration Wizard

Discord Bot 配置向导

在浏览器中填写 Discord Token、服务器 ID、频道/角色 ID、AI SK、OpenAI 兼容接口、投票系统和运行监控。Zeabur 在线模式可直接保存配置并重启 Bot。

本地处理 本页面可本地生成配置；部署到 Zeabur 后会通过密码保护并保存到服务器持久化目录。
1

基础信息

填写 Bot Token 和 Discord 服务器 ID。服务器 ID 需要在 Discord 开发者模式中复制。

2

角色与常用频道

每行一个 ID。暂时不用的频道可以留空，生成结果会写成 null。

3

Forum / Thread 自动化

用于分析或清理不活跃帖子；不需要时保持 disabled。

4

身份组申请

如果暂时不用身份组申请功能，全部留空即可。

5

AI 答疑接口

可配置 FastGPT，也可以直接配置 OpenAI 兼容接口，例如 OpenAI、DeepSeek、硅基流动、OpenRouter 等。

OpenAI 兼容接口填写示例 https://api.openai.com/v1/chat/completions https://api.deepseek.com/chat/completions 也可以只填 https://api.openai.com/v1 或服务商根地址；保存时会自动补齐 /chat/completions。普通文本模型选“纯文本兼容”，视觉模型可选“多模态/图片”。SK/API Key 会写入服务器 config.json，不要提交到 GitHub。
安全提醒 SK / API Key 会持久化保存到服务器的 /app/data/config.json，不要提交到 GitHub。在线页面受 JSBOT_WEB_PASSWORD 保护。
6

社区治理 / 投票系统

用于处罚上诉、议案提案、辩论 Forum 和投票截止时间。下面用“小时”填写，保存时会自动转成毫秒。

7

自助身份组

配置 Bot 后续发送的身份组领取按钮。用户可点击按钮领取或取消身份组。

分组字段说明 ID 用于按钮标识，标签展示给用户，角色 ID 为 Discord 身份组 ID，Emoji 可选。模式建议使用 toggle（领取/取消），也可选择 grant（只领取）或 remove（只移除）。角色 ID 必须是 17–20 位数字。
8

消息统计查询

控制谁可以查询服务器消息统计数据。普通用户可私密查询自己，白名单用户可查询任意 DCID。

9

运行监控

用于展示 Bot 在线状态、Ping、运行时间和被监控角色人数。监控频道可留空，Bot 命令也可后续创建/更新。

10

导入 / 重置

可以导入已有 config.json 继续编辑。

11

在线保存 / Bot 控制

在 Zeabur 域名访问时，配置会保存到服务器的持久化 data/config.json。

如果 Discord 聊天中看不到 /同步指令，可点击上方按钮手动触发重新部署。
